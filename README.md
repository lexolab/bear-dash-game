# Dino Dash

Landing page + mini game estilo runner, inspirado en el dinosaurio offline de Google.

## Cómo correrlo

Abre `index.html` en el navegador o levanta un server estático:

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`.

## Controles

- `Space` o `↑` para saltar
- Tap/click en móvil
- `Restart` para reiniciar

## Archivos

- `index.html` — landing page
- `styles.css` — diseño visual y responsive
- `game.js` — lógica del juego
